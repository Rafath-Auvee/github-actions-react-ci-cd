Assignment on module 5
Assignment: GitHub Actions Fundamentals

Problem Statement

A software company wants to automate the testing and build process of their React application. Currently, developers manually test and build the project before deployment, which takes time and may introduce human errors.

Your task is to create a simple CI pipeline using GitHub Actions that automatically runs whenever code is pushed to the development branch.

The pipeline must use a self-hosted runner instead of a GitHub-hosted runner.

Concepts Covered

Students should understand:

CI/CD basics and benefits

GitHub Actions architecture

Workflow

Jobs

Steps

Runners

YAML workflow structure

Self-hosted runner usage

Pipeline debugging

Expected Outcome

After completing the assignment:

The workflow should automatically run after pushing code to the development branch

The self-hosted runner should execute the pipeline

The React application should successfully build through GitHub Actions

Students should be able to identify and debug pipeline failures from workflow logs

Screenshot of failed pipeline debugging

CI/CD
